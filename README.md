# Personal Portfolio Website

A modern, responsive, and visually engaging **Personal Portfolio Website** built to showcase my skills, projects, and experience as a Web Developer.

---

## About The Project

This portfolio website represents my professional identity and highlights my work in web development.  
It is designed with a clean and user-friendly interface, focusing on performance, accessibility, and responsive design.

The main goal is to present my projects in an organized and visually appealing way while making it easy for clients and collaborators to connect with me.

---

## Features

- Fully Responsive Design (Mobile, Tablet, Desktop)
- Clean & Modern UI/UX
- Projects Showcase Section
- Skills & Technologies Section
- About Me Section
- Contact Form
- Fast Loading & Performance Optimized

---

## Technologies Used

- HTML5  
- CSS3  
- JavaScript
